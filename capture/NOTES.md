# Macquarie capture notes

## Scope

The capture covers the public homepage and personal banking login at desktop and mobile widths. Mars Bank keeps the source site's compact black navigation, large editorial hero, blue action color, open white sections, and centered login panel.

## Motion

- The homepage hero rotates through four numbered stories.
- The desktop header uses a slim utility bar above the main navigation.
- The mobile header collapses to a menu button, wordmark, search, and login.
- The homepage uses horizontal card carousels and a back-to-top control.

## Deliberate changes

- Mars Bank replaces all Macquarie names and visible logos.
- The final Mars Bank logo is undecided. The first release uses a wordmark and a temporary Mars mark.
- Mars Bank uses Mars banking copy and synthetic token balances.
- The login is a clearly labeled demo with prefilled fictional credentials.
- The authenticated banking application is original because the source application requires real authentication.

## Excluded production services

The build excludes analytics, advertising, anti-bot endpoints, CSRF endpoints, authentication, payments, and production banking APIs. Local route handlers return synthetic fixtures.
